
# PawHome — Animal Shelter Website

PawHome is a web application designed to help homeless animals find loving families.

## Project Description

The website allows visitors to explore animals available for adoption and learn about the animal shelter.

## Features

- Responsive homepage
- Animal catalog with photos and descriptions
- Filtering animals by category
- Login and registration interface
- Client-side form validation
- Mobile-friendly navigation

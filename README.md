# Pet Adoption Web Application

Панасыз жануарлар мен жаңа иегерлерді байланыстыруға арналған веб-қосымша.

## 🛠 Технологиялар
* **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
* **Backend:** PHP (Native / OOP)
* **Database:** MySQL

## Жоба мүмкіндіктері
- Пайдаланушыларды тіркеу және авторизациялау
- Жануарлар каталогы және іздеу/сүзу жүйесі
- Жануарларды асырап алуға өтініш беру
- Әкімшіге арналған CRUD (Жануарларды қосу, өңдеу, жою) панелі

## Дерекқор құрылымы
Жоба 3 негізгі кестені қолданады: `users`, `pets`, `adoptions`.
